## Executive Summary

The branch adds scoped local stale-prefix cleanup and improves ignore, repository-exclude, and branch discovery behavior. However, canonical re-mining remains incomplete because remote ingestion only uploads currently eligible files and has no reconciliation or deletion mechanism, leaving stale remote rows—including when discovery is empty. Additional discovery-accounting and `.env` boundary concerns remain, so the branch requires revision.

## Changed Files

- crates/mempalace-cli/src/main.rs
- crates/mempalace-ingest/src/lib.rs
- docs/CLI-Surface.md
- docs/Mined-Storage.md

## Blocking Issues

- Remote canonical mines do not purge stale rows: The remote execution path sends only currently eligible files through ingest batches and provides no snapshot reconciliation or deletion semantics. Remote-only mines therefore retain stale secret/excluded sources, and combined mines clean only the local copy; empty discovery cannot trigger remote cleanup.

## Non-Blocking Issues

- Tracked skip metadata is dropped from branch discovery results: discover_project_branch_sources retains filesystem-walk accounting but discards tracked skip counts and skip records, causing tracked secret-shaped files, missing files, rejected symlinks, or entries hidden by ignored parents to disappear from branch summaries.
- Secret detection is broader than the documented .env boundary: secret_path_kind uses a .env prefix check, so unrelated names such as .envoy.rs and .environment are treated as secret-shaped and may be excluded.

## Missing Tests

- Remote-only canonical re-mine deleting stale remote rows.
- Combined-route canonical re-mine deleting stale rows in both local and remote copies.
- Empty-source remote canonical re-mine purging existing project rows.
- Branch discovery preserving tracked skip counts and secret skip records.
- End-to-end branch ingestion for changed tracked files beneath ignored directories.
- Boundary cases for .envoy.rs, .environment, and similar names.

## Disputed Issues

- Whether names such as .envoy.rs and .environment are defects depends on the intended, documented secret-file policy, although the current behavior is broader than that stated boundary.

## Outstanding Concerns

- The central canonical-mine safety guarantee is route-dependent: local ingestion performs the stale-prefix cleanup, while remote ingestion does not.
